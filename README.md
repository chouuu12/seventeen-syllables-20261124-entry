A haiku about debugging, written for the [make.fun bounty](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605).

> breakpoint holds its breath
> the value I leaned on lies
> it was my typo

## Run

```sh
node main.ts
```

`main.ts` reads `haiku.txt`, validates it (UTF-8 text, 1–200 characters, not only whitespace, three lines), and writes it to `/output/entry.txt`.
